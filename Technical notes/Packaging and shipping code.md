The code packaging is an important task that involves allow the code that is up and running in its own PC on another machine. There are a plethora of various information regarding dependencies, versions and et cetera to take into consideration.

The main source code it is often referred to as an *artifact*. It is important to make sure that the artifact could be run in each possible machine. Usually this task is well performed by **Docker**, still it is important to know all the relevant components and participants to ship a product. 
##### Dependencies

In Python, the tool that is used in order to manage packages is called *pip* (even though *uv* is another well known package manager).
