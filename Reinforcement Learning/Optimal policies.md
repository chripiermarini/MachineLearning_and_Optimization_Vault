A policy is said to be better than another one if its expected return is greater or equal of that of the other for all states. Given that the expected reward fora given policy is computed through the value function, we can say that $\pi^* \geq \pi \text{ if and only if } v_{\pi^*}(s) \geq v_{\pi}(s)$ for all states. The value of the *value function* for the optimal policy is called *optimal value function*.
